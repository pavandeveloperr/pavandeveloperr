## 🚀 What I'm building

**[MediQuery](https://github.com/pavandeveloperr/mediquery)** — Clinical document intelligence platform using agentic RAG. Upload medical PDFs, ask natural language questions, get grounded cited answers. Built with Next.js 14, TypeScript, Gemini API, pgvector, and Supabase. Live at [mediquery.vercel.app](https://mediquery-psi.vercel.app)
